# Slideshow Video Creator Pro v4.5.0

## Νέο: ενημερώσεις από την εφαρμογή
- **Settings → Ενημερώσεις**: εγκατεστημένη/διαθέσιμη έκδοση και έλεγχος GitHub Releases.
- Λήψη, έλεγχος SHA-256, εγκατάσταση και αυτόματη επανεκκίνηση, για Python και Windows `.exe`.
- Διατηρούνται ρυθμίσεις, API keys, προφίλ, projects, μουσική, μοντέλα και προσωπικά αρχεία.
- Αν η νέα έκδοση δεν ξεκινήσει, επαναφέρονται τα προηγούμενα αρχεία εφαρμογής.

## Επίσης σε αυτή την έκδοση
- Νέο περιβάλλον εργασίας, βιβλιοθήκη διαθέσιμων media και storyboard με ομάδες.
- Κοινό «Εφαρμογή σε» για Captions / Slide Design, live templates και rich text editor.
- AI Director με πολλαπλούς OpenAI-compatible providers, προαιρετικό vision,
  μικρογραφίες και μεγάλο viewer για γρήγορες περιγραφές media.
- Βελτιώσεις επαναφοράς παραθύρων μετά το minimize / Show Desktop.

## Windows, χωρίς Python
Κατεβάστε το **SlideshowVideoCreator_v4.5.0_windows.zip**, αποσυμπιέστε το σε έναν
φάκελο στον οποίο έχετε δικαίωμα εγγραφής και εκτελέστε το **SlideshowVideoCreator.exe**.
Το ZIP περιλαμβάνει τις εξαρτήσεις και FFmpeg. Το `.exe` χρειάζεται και τον φάκελο
`_internal` δίπλα του — μην αντιγράφετε μόνο το εκτελέσιμο.

Για υπάρχουσα έκδοση πριν από την v4.5.0, χρειάζεται μία χειροκίνητη εγκατάσταση αυτής
της έκδοσης. Από την v4.5.0 και μετά οι ενημερώσεις γίνονται μέσα από την εφαρμογή.

Το **source.zip** είναι για εγκαταστάσεις Python. Το **update-manifest.json**
χρησιμοποιείται αυτόματα από τον updater.
